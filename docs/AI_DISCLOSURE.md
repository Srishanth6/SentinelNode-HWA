# AI tool disclosure

HackWithAditya 2026 rules allow coding assistants and AI APIs as long as they are disclosed and the team can explain the code.

- **Tools used:** an AI coding assistant (Grok Bot) helped write parts of the Python code, the firmware, the tests and the documentation, under the team's direction. The team reviewed every file.
- **External code:** none copied. The libraries used are listed in `requirements.txt` and at the top of the firmware: Adafruit sensor libraries, OneWire, DallasTemperature, ArduinoJson, PubSubClient, scikit-learn, NumPy and FastAPI.
- **Data:** all data in this repo is synthetic, from `sim/simulator.py`.
